# 开放研究问题

本文件记录尚未成为架构事实的问题。候选方向只有在实验定义、实现和证据齐备后，才能转入 `docs/architecture.md` 或 `docs/status.md` 的 Confirmed/Verified 部分。

## 数据与策略

- 如何取得比“下一状态代理”更接近真实控制意图的 Piper X action？
- 双 RGB 是否足以支持第一版 π0.5，depth 应作为模型输入、评测信号还是只用于诊断？
- 真机与 Isaac Sim 的 observation/action 分布如何对齐并量化差异？
- action chunk 执行多少步后重新观测和推理，如何处理通信或执行延迟？

## 易碎性

- “损伤”应由形变、破裂、峰值接触、累积冲量、夹持力还是任务后检查定义？
- Isaac Sim 中哪些物理模型能稳定、可重复地表达目标属性？
- 仿真指标与真实物体损伤之间如何标定？
- 怎样同时报告抓取成功、物体完整性、速度和失败模式？

## 感知与标定

- 外部 RGB-D 与腕部相机分别承担哪些观测角色？
- 需要怎样的内参、外参、时间同步和重标定流程？
- 深度缺失、反光、遮挡和运动模糊如何进入数据质量判定？

## 实验设计

- 第一组固定物体、初始位姿和随机化范围是什么？
- 每个配置需要多少次运行，如何区分无效运行和任务失败？
- 应保存哪些原始信号，才能在未来修改指标而无需重新采集？
